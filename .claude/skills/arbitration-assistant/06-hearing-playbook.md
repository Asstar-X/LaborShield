# 庭审质证对抗、HR 抗辩拆解与调解底线实战手册 (`06-hearing-playbook.md`)

本文件用于指导 `/hearing` 命令及 `/docket` 生成《07_庭审举证质证与调解应对手册.md》，帮助无律师代理的劳动者在仲裁庭审调查、举证质证、辩论及庭上调解四个阶段保持专业、冷静、不掉入自认陷阱。

---

## 一、 中国劳动人事争议仲裁庭审四阶段标准流程与纪律

1. **第一阶段：核对当事人身份与宣布庭审纪律**
   - 必须携带：本人身份证原件、全套证据**原件**（劳动合同原件、解除通知原件、银行流水原件、存有原始微信聊天与录音的手机终端）。
   - 被申请人未到庭或中途退庭的，仲裁庭依法缺席审理并缺席裁决。
2. **第二阶段：仲裁庭调查（宣读申请书、答辩状、核对 18 项要素与举证质证）**
   - **黄金原则**：仲裁员发问时，回答必须**简短、精准、与《02_劳动人事争议仲裁要素表》完全一致**！凡是确定事实回答“是/否/具体日期金额”，凡是记不清的细节回答“以申请人提交的书面证据第 X 项记载为准”，严禁当庭随意猜测或夸大。
3. **第三阶段：仲裁庭辩论与最后陈述**
   - 聚焦两点：① 被申请人未能完成《调解仲裁法》第6条规定之法定举证责任；② 被申请人解除行为在实体事由与法定程序（未经培训调岗、未通知工会）上双重违法。
4. **第四阶段：仲裁庭调解**
   - 双方自愿达成调解的，仲裁庭制作《仲裁调解书》，经双方签收后即具有与生效判决同等的强制执行力（任何一方均不得反悔起诉）。

## 二、 用人单位 HR / 代理律师 8 大经典抗辩拆解与“三性”质证公式

当被申请人在庭上提交证据或提出以下 8 类高频抗辩时，申请人按**“真实性、合法性、关联性及证明目的”**四维标准逐一反驳：

| 序号 | 用人单位常见抗辩与提交证据 | 申请人当庭标准“三性”质证与拆解话术 |
| :---: | :--- | :--- |
| **1** | **以《员工手册》主张“严重违反规章制度（第39条第2项）”无偿开除** | “对该《员工手册》的真实性、合法性、关联性及证明目的均不予认可：① 被申请人未举证证明该规章制度经过职工代表大会或全体职工讨论、与工会或职工代表平等协商确定之法定民主程序（违反《劳动合同法》第4条）；② 被申请人从未向申请人公示或组织培训签收；③ 申请人不存在其所指控的违纪事实，且其规章制度将轻微瑕疵无限上纲上线为‘严重违纪’，明显违背比例原则与公平合理原则。” |
| **2** | **以“绩效考核 C/D 级、PIP 不达标”主张“不能胜任工作辞退（第40条第2项）”** | “对考核表的合法性、关联性及证明目的均不予认可：依据《劳动合同法》第40条第（二）项，以不能胜任工作解除合同必须同时具备四个递进法定要件：① 事先经申请人确认的明确量化考核标准；② 客观公正证明第一次考核不胜任；③ **经过专项培训或者依法调整工作岗位**；④ **培训或调岗后经第二次考核仍不能胜任工作**。被申请人单方主观打分，且未履行培训或调岗及二次考核程序，直接辞退构成典型违法解除（2N）。” |
| **3** | **以“部门裁撤、业务线调整、岗位取消”主张“客观情况发生重大变化（第40条第3项）”** | “对证明目的不予认可：① 企业内部自主进行的部门合并、架构调整属于日常经营决策范畴，不属于订立劳动合同时所依据的客观情况发生重大变化（如不可抗力、法规变化、特许经营被收回）；② 被申请人从未就变更劳动合同内容与申请人进行过平等诚意协商，亦未提供合理替代岗位，径行单方辞退属违法解除。” |
| **4** | **口头辞退或关闭权限后，反咬申请人“连续旷工 3 天自动离职”** | “对被申请人单方制作的《考勤异常表》及《催告返岗函》真实性、合法性、证明目的均不予认可：① 系被申请人于 XXXX年X月X日先行单方口头辞退并关停申请人企业微信及门禁打卡权限，导致申请人客观上无法进入办公场所打卡（有证据6、证据7为证）；② 被申请人在制造无法打卡既成事实后恶意倒打一耙指控旷工，违背诚实信用原则。” |
| **5** | **提交无申请人亲笔签字的单方《考勤统计表》否认加班事实** | “对该打印表格的真实性、合法性、关联性均不予认可：该表系被申请人单方在电脑中编辑打印，既无申请人本人签字确认，亦非考勤系统底层不可篡改之原始数据日志。申请人已提交加班审批单及工作群深夜交付成果记录（证据5），请求仲裁庭对被申请人单方打印件不予采信。” |
| **6** | **主张“基本工资即加班费计算基数（如按最低工资 2,520 元算加班费）”** | “对被申请人的计算基数不予认可：申请人月标准固定工资为 18,000.00 元，被申请人为规避法定加班费成本，在形式上将工资人为拆分为极低的基本工资与各种固定津贴，但各项津贴均按月固定全额发放，依法应以申请人正常出勤月实际应得工资作为加班费核算基数。” |
| **7** | **主张“公司实行不定时工作制 / 综合计算工时制，无需支付加班费”** | “请被申请人当庭出示人力资源和社会保障行政部门出具的、在有效期内且明确涵盖申请人所在岗位的《实行不定时工作制/综合计算工时工作制行政许可决定书》原件！若无有效行政审批许可，被申请人单方约定无效，仍应按标准工时制支付加班费。” |
| **8** | **以“员工手册规定当年年假逾期不休自动作废”拒绝支付未休年假工资** | “对证明目的不予认可：依据《企业职工带薪年休假实施办法》第九条、第十条，用人单位应当根据生产、工作具体情况统筹安排职工休年休假；仅当**用人单位已安排职工休年休假，且有证据证明系职工本人因个人原因书面提出不休年休假**时，才可只支付正常工资。被申请人从未统筹安排申请人休假，其格式免责条款因排除劳动者法定权利而无效（《劳动合同法》第26条）。” |

## 三、 调解谈判三级现金折现模型與调解书避坑铁律

劳动仲裁案件中，仲裁员在庭前和庭审结束前均会主持调解。申请人应遵循以下量化策略：

### 1. 三级现金折现计算基准
- **A 档（理想目标额 = 法定全额 × 85% ~ 95%）**：适用于证据铁板钉钉（如盖章辞退通知书违法事由明显）、被申请人担心败诉裁判文书上网或影响合规审计的情形。
- **B 档（务实折中额 = 法定全额 × 70% ~ 80%）**：若案件属于非终局裁决，被申请人有极大概率通过“一审起诉 + 二审上诉”拖延 6~10 个月。当场拿到 75% 确定性现金往往优于 10 个月后经强制执行拿到的 100% 账面额。
- **C 档（绝对谈判底线 = 法定全额 × 60% ~ 65%）**：低于此底线（尤其是已满足第47条一裁终局条件的请求项），应果断告知仲裁员：“分歧过大，申请不再调解，请求仲裁庭依法及时作出裁决。”

### 2. 签署《仲裁调解书》必查四大避坑条款
1. **明确到账截止日与收款账户**：必须写明“被申请人于 XXXX年X月X日前一次性支付至申请人本人 XX 银行账户（卡号：XXXX）”，切忌写模糊的“月底前”或“走完内部审批后”。
2. **必须要求明确“税后实得净额”**：“被申请人向申请人一次性支付调解款人民币 XX,XXX.XX 元（**税后净额，如涉及个人所得税等税费均由被申请人自行承担**）”，防止单位打款时恶意按 20% 劳务报酬或高额个税扣减。
3. **必须写入“逾期付款惩罚性违约金条款”**：“如被申请人未按上述约定期限足额支付任意一期款项的，申请人有权就未付部分及**额外加付人民币 XX,XXX.XX 元违约金（或按原仲裁请求全额）**直接向人民法院申请强制执行。”
4. **离职证明开具规范**：调解书可一并写明“被申请人于付款当日向申请人出具符合《劳动合同法实施条例》第二十四条规定的《解除劳动合同证明》，不得记载任何不利于申请人再就业之负面评价”。
