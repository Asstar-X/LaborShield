# 准入三关、证据“三性”审查与证明目的方法论 (`04-evidence-methodology.md`)

本文件定义 `/audit` 与 `/docket` 必须强制执行的**三大前置硬性关卡 (Hard Gates)**、**举证责任倒置规则**、**电子证据“三连闭环”规范**及**标准化证明目的公式库**。

---

## 一、 立案前置“三大硬性准入关卡” (`Hard Gates` — 评分与起草前必跑)

在评估证据强弱或起草文书前，必须依次执行以下三道关卡：

### Gate 1：主体适格与法律关系定性关 (`Subject & Relationship Gate`)
| 核验情形 | 判定结论 | 处置指令与救济路径 |
| :--- | :---: | :--- |
| 劳动者在争议发生时**已达到法定退休年龄且已开始依法享受基本养老保险待遇** | **FAIL（硬性拦截）** | 根据《最高法劳动争议解释（一）》第32条，双方属于**民事劳务关系**，劳动人事争议仲裁委员会不予受理。立即停止起草劳动仲裁申请书，指导当事人直接向基层人民法院提起民事劳务合同诉讼。 |
| 劳动者已达法定退休年龄，但**未享受养老保险待遇且非因本人原因未办退休** | **FLAG（高风险标记）** | 各地裁审口径存在差异（部分地区按劳务关系，部分地区按劳动关系保护）。必须在报告中明确提示用户先向当地仲裁院立案窗口核实是否出具《不予受理通知书》（凭不予受理通知书可转法院起诉）。 |
| 合同签署主体、发薪主体、社保缴纳主体不一致（**关联企业混同用工**）或属**劳务派遣** | **FLAG（双被申请人）** | 依据《劳动合同法》第92条及混同用工司法解释，自动将实际用工单位与合同签署/劳务派遣单位列为**第一被申请人、第二被申请人**，诉请承担连带赔偿责任。 |
| 被申请人已注销、被吊销营业执照或进入破产程序 | **FLAG（主体变更）** | 若已注销且未经合法清算，列全体股东/清算组成员为被申请人；若已进入破产程序，指导向破产管理人申报职工债权（无需经过普通仲裁）。 |
| 劳动者与用人单位均适格、存续正常 | **PASS** | 正常进入下一关卡。 |

### Gate 2：仲裁时效与中断审查关 (`Statute of Limitations Gate`)
| 核验情形 | 判定结论 | 处置指令与救济路径 |
| :--- | :---: | :--- |
| 解除/终止赔偿金或经济补偿金：距收到解除通知或实际离职之日 **≤ 1 年** | **PASS** | 符合《劳动争议调解仲裁法》第27条第1款（1年一般仲裁时效）。 |
| 拖欠劳动报酬：仍在职，或离职后距劳动关系终止之日 **≤ 1 年** | **PASS** | 符合《劳动争议调解仲裁法》第27条第4款（存续期间不受1年限制，离职后1年内提出）。 |
| 未订立书面劳动合同二倍工资差额：距用工满1年之日（或补订合同日）**> 1 年** | **FAIL / FLAG** | 核查是否已超1年时效（深圳等地按月分别起算1年时效，浙江等地自满1年之日整体起算1年）。超期部分必须剔除或提示时效抗辩败诉风险。 |
| 表面距争议发生已 **> 1 年**，但存在微信讨薪、律师函、向劳动监察投诉或调解组织调解记录 | **FLAG（时效中断）** | 依据《劳动争议调解仲裁法》第27条第2、3款，必须将讨薪记录或投诉回执编入《证据目录》，在申请书中专门论述**“仲裁时效依法中断并重新计算”**。 |
| 距争议发生已 **> 1 年** 且无任何时效中断、中止证据 | **FAIL（红灯阻断）** | 明确告知用户：一旦被申请人在庭审中提出时效抗辩，仲裁委将直接裁决驳回仲裁请求。 |

### Gate 3：管辖权精准锚定关 (`Jurisdiction Gate`)
| 核验情形 | 判定结论 | 处置指令与救济路径 |
| :--- | :---: | :--- |
| **劳动合同履行地（实际办公地）**与**用人单位注册地**一致 | **PASS** | 锚定该区/县劳动人事争议仲裁委员会（若符合市直管注册资本/外资标准则锚定市级仲裁院）。 |
| 异地办公（如注册地在北京朝阳，实际办公与社保缴纳在深圳南山） | **PASS（优先履行地）** | 依据《劳动争议调解仲裁法》第21条，优先建议向**劳动合同履行地（实际工作地）**仲裁委提起，降低劳动者异地奔波成本，并在证据目录中强化“工作地点在履行地”的证明（如办公租约、当地社保、打卡定位）。 |

## 二、 证据“三性”红黄绿灯诊断矩阵

在 `/audit` 阶段，对每一份证据按**真实性（Authenticity）、合法性（Legality）、关联性（Relevance）**进行分级诊断：

| 诊断等级 | 典型证据形态 | 仲裁庭采信度与处置动作 |
| :---: | :--- | :--- |
| **🟢 绿灯（充分铁证）** | • 加盖被申请人公章或合同专用章的《劳动合同》《解除劳动合同通知书》《离职证明》<br>• 银行柜台或手机银行导出的带电子印章《工资交易流水明细》<br>• 国家税务总局“个人所得税 App”导出的《收入纳税明细》与《纳税记录》<br>• 人社局官方导出的《社会保险参保缴费明细表》<br>• 国家企业信用信息公示系统打印的企业信息报告 | **直接采信**。按标准五列表格直接编入《证据目录》，注明“原件/官方电子凭证核对无异”。 |
| **🟡 黄灯（瑕疵待补强）** | • **微信/钉钉/飞书工作群或私聊截图**（缺少对方实名主页或组织架构页面）<br>• **现场谈话录音**（仅有音频文件 `.mp3/.m4a`，无逐字文字整理稿或无时间戳）<br>• **无公章的电子 Offer 邮件**（未展示完整发件人企业邮箱域名头部及原始邮件载体）<br>• **手机拍摄的排班表/打卡机照片**（无公司标识或时间水印） | **需按“三连闭环”补强后方可提交**：<br>1. 微信/钉钉必须补截对方个人信息页/企业组织架构实名页/实名转账校验页；<br>2. 录音必须生成带 `[MM:SS]` 秒级时间戳的《录音文字整理稿》；<br>3. 对单位掌握的考勤与工资台账，自动追加《责令被申请人提供证据申请》。 |
| **🔴 红灯（致命盲区/反噬）** | • 劳动者亲笔签署的《离职申请表》勾选了“个人原因/家庭原因/职业规划”且无胁迫铁证<br>• 双方已签署《协商解除劳动合同协议书》载明“双方再无任何劳动争议”且款项已付清<br>• 证据之间存在明显时间轴矛盾（如声称某日加班但当日有异地旅游消费记录） | **高危阻断预警**。严禁隐瞒不利证据，必须向当事人客观揭示败诉风险及被申请人可能反击的质证点。 |

## 三、 举证责任倒置与“书证提出命令”操作规范

依据《劳动争议调解仲裁法》第六条、第三十九条及《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第四十二条、第四十四条：

1. **法定倒置事项**：因用人单位作出的**开除、除名、辞退、解除劳动合同、减少劳动报酬、计算劳动者工作年限**等决定而发生的劳动争议，**由用人单位负举证责任**。
2. **用人单位法定义务台账**：
   - 《工资支付暂行规定》第六条第三款：用人单位必须书面记录支付劳动者工资的数额、时间、领取者的姓名以及签字，并**保存两年以上备查**。
   - 考勤打卡原始后台数据、绩效考核原始打分表及规章制度民主制定与公示记录，均属于由用人单位掌握管理的证据。
3. **文书植入策略**：只要劳动者缺乏完整工资条或完整考勤表，`/docket` 必须在《仲裁申请书》第三部分自动写入**《责令被申请人限期提供证据申请》**，请求仲裁庭限期责令单位提交上述台账；单位拒不提交的，请求仲裁庭依法推定申请人的工资数额及加班主张成立。

## 四、 《证据目录》“证明目的”标准编写公式库

> **强制语法规则**：每一条证明目的**必须以 `"证明"` 二字开头**（`tools/verify_docket.py` 强制校验），遵循**“证明 + 客观事实要素 + 指向的法律要件/仲裁请求”**公式，字数控制在 35~90 字之间。

| 证据组类别 | 标准化“证明目的”示范文本（可直接套用与微调） |
| :--- | :--- |
| **证据组1：主体资格与工商档案** | `证明申请人系符合法定劳动年龄之适格劳动者，被申请人系依法设立并存续之企业法人，双方具备劳动人事争议仲裁之适格主体资格，且贵委对本案依法享有管辖权。` |
| **证据组2：劳动合同与入职材料** | `证明申请人于 XXXX年X月X日入职被申请人处担任 XX 岗位，双方依法建立劳动关系，约定工作地点为 XX，月标准工资为人民币 XX,XXX.XX 元（对应支持全部仲裁请求之劳动关系基础）。` |
| **证据组3：银行流水与个税App明细** | `证明被申请人按月向申请人发放劳动报酬之事实，且申请人离职前12个月（XXXX年X月至XXXX年X月）月平均应得工资（税前应发）为人民币 XX,XXX.XX 元，作为核算经济补偿/赔偿金及加班费之法定基数（对应支持请求1、请求2、请求3）。` |
| **证据组4：社保参保缴费明细** | `证明被申请人自 XXXX年X月起为申请人缴纳社会保险，连续工作年限为 X年X个月（折算工龄系数 N=X.X），且累计工作年限已满 X 年，依法享有每年 X 天带薪年休假（对应支持请求1、请求3）。` |
| **证据组5：考勤记录与加班审批截图** | `证明申请人在职期间严格遵守考勤纪律，且于 XXXX年X月至X月期间应被申请人安排在休息日加班共计 XX 小时，被申请人未安排补休亦未依法支付 200% 加班工资差额（对应支持请求4）。` |
| **证据组6：解除劳动合同通知书** | `证明被申请人于 XXXX年X月X日单方解除与申请人的劳动合同，且其所称解除事由缺乏事实与法律依据、未履行法定培训调岗及通知工会程序，构成违法解除劳动合同（对应支持请求1之 2N 赔偿金）。` |
| **证据组7：沟通微信截图与谈话录音** | `证明被申请人人事负责人向申请人宣布单方辞退决定、承认拖欠 XXXX年X月工资及未休年休假天数，且双方未能就解除补偿达成一致之客观事实（含微信号实名主体锁定及录音秒级时间戳逐字稿，对应支持请求1至请求4）。` |
