# 中国劳动人事争议核心法规库与地方裁审标准 (`02-statutory-rules.md`)

本文件为 `LaborShield` 在进行赔偿核算（`/calc`）、准入诊断（`/audit`）及文书起草（`/docket`）时的法定准据库。严禁编造不存在的法条款项。

## 一、 核心法律、行政法规与司法解释速查矩阵

| 争议类型 | 核心法条与条款精确引用 | 适用要件与实务红线 |
| :--- | :--- | :--- |
| **1. 违法解除劳动合同赔偿金 (`2N`)** | • 《中华人民共和国劳动合同法》第四十七条、第四十八条、第八十七条<br>• 《中华人民共和国劳动合同法实施条例》第二十五条、第二十七条 | • 用人单位违反本法规定解除或终止劳动合同，劳动者不要求继续履行或已无法继续履行的，按经济补偿标准的**二倍（2N）**支付赔偿金。<br>• **排他规则**：用人单位支付了赔偿金的，不再支付经济补偿（`N`），亦**不适用**第四十条之未提前30日代通知金（`+1`）。 |
| **2. 无过失性辞退 (`N+1`)** | • 《中华人民共和国劳动合同法》第四十条、第四十六条第（三）项、第四十七条<br>• 《中华人民共和国劳动合同法实施条例》第二十条 | • 仅限三类法定情形：① 医疗期满不能从事原工作及另行安排的工作；② **不能胜任工作，经过培训或者调整工作岗位，仍不能胜任工作**；③ 客观情况发生重大变化，经协商未能就变更劳动合同达成协议。<br>• 未提前30日书面通知的，额外支付 1 个月工资（`+1`），**代通知金按劳动者上一个月的工资标准确定**（不受社平3倍封顶限制）。 |
| **3. 劳动者被迫解除劳动合同 (`N`)** | • 《中华人民共和国劳动合同法》第三十八条、第四十六条第（一）项、第四十七条 | • 用人单位存在：未及时足额支付劳动报酬、未依法为劳动者缴纳社会保险费、未按照劳动合同约定提供劳动保护或者劳动条件、规章制度违反法律规定损害劳动者权益等情形。<br>• **实务刚性前提**：劳动者必须以**上述法定过错为由**向单位发出明确解除通知（如 EMS 邮寄《被迫解除劳动合同通知书》）。若离职申请填写“个人原因/职业发展/家庭原因”，仲裁庭一般不予支持经济补偿金。 |
| **4. 协商一致解除与裁员 (`N`)** | • 《中华人民共和国劳动合同法》第三十六条、第四十一条、第四十六条第（二）（四）项 | • **由用人单位提出**并与劳动者协商一致解除劳动合同的，支付 `N`（若由劳动者主动提出辞职协商解除，无 `N`）。<br>• 经济性裁员（第41条）需提前30日向工会或全体职工说明情况并向劳动行政部门报告，支付 `N`（无 `+1`）。 |
| **5. 固定期限合同期满终止 (`N`)** | • 《中华人民共和国劳动合同法》第四十四条第（一）项、第四十六条第（五）项 | • 除用人单位维持或者提高劳动合同约定条件续订劳动合同，劳动者不同意续订的情形外，固定期限劳动合同期满终止的，用人单位应当支付 `N`。<br>• 若已连续订立二次固定期限劳动合同（第14条第2款第3项），劳动者提出续订无固定期限合同而单位单方终止的，构成**违法终止（2N）**（上海部分早期口径除外，现全国主流口径均支持 2N）。 |
| **6. 未订立书面劳动合同二倍工资差额** | • 《中华人民共和国劳动合同法》第八十二条第一款<br>• 《中华人民共和国劳动合同法实施条例》第六条、第七条 | • 自用工之日起超过一个月不满一年未与劳动者订立书面劳动合同的，应当向劳动者每月支付二倍的工资。<br>• 计算窗口：**用工满一个月的次日起至补订书面劳动合同的前一日（或满一年的前一日）止，最长不超过 11 个月**。 |
| **7. 离职未休带薪年休假工资报酬** | • 《职工带薪年休假条例》第三条、第五条<br>• 《企业职工带薪年休假实施办法》第十条、第十一条、第十二条 | • 累计工作满1年不满10年休5天；满10年不满20年休10天；满20年休15天。<br>• 当年度折算：`floor((当年度在本单位已工作日历天数 ÷ 365) × 全年应享天数) - 已休天数`（**不足1整天部分不享受年休假**）。<br>• 报酬标准：日工资收入的 300%（含已支付的正常工作期间 100% 工资，**仲裁实际追索 200% 差额**）。 |
| **8. 拖欠工资与加班费** | • 《中华人民共和国劳动法》第四十四条<br>• 《中华人民共和国劳动合同法》第三十条第一款<br>• 《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第四十二条 | • 日工资 = 月基数 ÷ `21.75`；小时工资 = 日工资 ÷ `8`。<br>• 工作日延时加班 **150%**；休息日加班且不能安排补休 **200%**；法定休假日加班 **300%**（法定休假日加班不得以补休代替加班费）。<br>• 劳动者对存在加班事实负初步举证责任；劳动者有证据证明用人单位掌握加班事实存在的证据，用人单位不提供的，由用人单位承担不利后果。 |
| **9. 工会通知程序与程序违法 (`2N`)** | • 《中华人民共和国劳动合同法》第四十三条<br>• 《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第四十七条 | • 用人单位单方解除劳动合同，**应当事先将理由通知工会**。<br>• 未建立工会的，是否已通知所在地地方工会或履行民主程序；用人单位违反法定程序且在一审起诉前未补正的，依法认定为违法解除（`2N`）。 |
| **10. 举证责任分配与倒置** | • 《中华人民共和国劳动争议调解仲裁法》第六条、第三十九条<br>• 《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第四十四条 | • 因用人单位作出的**开除、除名、辞退、解除劳动合同、减少劳动报酬、计算劳动者工作年限**等决定而发生的劳动争议，**由用人单位负举证责任**。 |

## 二、 《劳动争议调解仲裁法》第四十七条“一裁终局”实务规则

1. **法定条文**：
   - 第四十七条：下列劳动争议，除本法另有规定的外，仲裁裁决为终局裁决，裁决书自作出之日起发生法律效力：
     - （一）追索**劳动报酬、工伤医疗费、经济补偿或者赔偿金**，不超过当地月最低工资标准十二个月金额的争议；
     - （二）因执行国家的劳动标准在工作时间、休息休假、社会保险等方面发生的争议。
2. **最高法分项核算规则（《劳动争议司法解释（一）》第二十条）**：
   - 仲裁申请人的请求包含多项属于第四十七条第一项规定的劳动争议，**以当事人各单项请求金额分别核定**是否超过当地月最低工资标准十二个月金额（而非按所有请求加总金额判定）。
3. **程序战略价值**：
   - 一旦被认定为一裁终局，**劳动者不服可在收到裁决书 15 日内向基层法院起诉，但用人单位无权向基层法院起诉**（用人单位仅能在 30 日内向中级人民法院申请撤销裁决，且撤裁率极低）。
