# 中国劳动仲裁司法文书写作规范与法言法语指南 (`03-writing-style.md`)

本文件规范 `Drafter Agent` 与 `Reviewer Agent` 在起草和审校《劳动人事争议仲裁申请书》《仲裁要素表》《证据目录》时的语言风格、称谓纪律与表达范式。

---

## 一、 四大司法写作铁律 (Four Judicial Writing Mandates)

### 1. 法定称谓绝对统一（严禁混用民事诉讼称谓）
- 在劳动人事争议仲裁阶段，全文必须且只能使用：
  - **“申请人”**（指代劳动者本人，严禁写“我”、“本人”、“原告”、“上诉人”）；
  - **“被申请人”**（指代用人单位，若有两个单位则称“第一被申请人”、“第二被申请人”，严禁写“被告”、“老板”、“那家公司”、“XX领导”）；
  - **“贵委”** 或 **“仲裁庭”**（指代劳动人事争议仲裁委员会，严禁写“贵院”、“法官”）。
- `tools/verify_docket.py` 会对申请书正文中的 `"原告"`、`"被告"` 进行静态扫描并直接报错拦截（Exit Code 1）。

### 2. 彻底去情绪化与道德审判（Zero Emotional Rhetoric）
- 仲裁员日均审理大量案件，只看**“时间节点 + 客观行为 + 证据编号 + 违反法条 + 法律后果”**五要素闭环。
- **严禁出现**：感叹号堆砌（`！！！`）、反问句（`难道打工人的命就不是命吗？`）、人格侮辱或道德评判词汇（`黑心老板`、`无良公司`、`故意刁难`、`卸磨杀驴`、`PUA`、`画大饼`、`恶心至极`）。

### 3. 仲裁请求必须“明确、具体、可执行、分项独立”
- ❌ **错误写法**：“请求裁决被申请人赔偿申请人被辞退的各项损失、拖欠的工资和年假工资大概十万多元，并向申请人赔礼道歉。”
- ✅ **规范写法**：
  - “请求1：请求裁决被申请人向申请人支付违法解除劳动合同赔偿金人民币 126,000.00 元；”
  - “请求2：请求裁决被申请人向申请人支付 2024年8月1日至2024年8月15日正常出勤工资人民币 9,103.45 元（属《劳动争议调解仲裁法》第四十七条一裁终局请求项）；”

### 4. “事实与理由”标准四段式结构
1. **第一段（劳动关系建立与履行概况）**：写明入职日期、工作岗位、劳动合同签订期限、工作地点、约定的工资标准与构成、离职前12个月月平均应得工资数额。
2. **第二段（争议发生与违法解除/欠薪事实）**：按精确年月日客观陈述用人单位作出解除决定的过程（或拖欠工资、加班、未休年假的事实），指出单位行为在实体与程序上的违法点（如：未提前说明理由、未经法定培训或调岗、未事先通知工会）。
3. **第三段（法律适用与各项金额核算依据）**：援引《劳动合同法》《劳动法》《职工带薪年休假条例》具体条款，逐项列明每笔诉求的计算公式。
4. **第四段（结语与统括请求）**：“综上所述，被申请人的上述行为严重侵害了申请人的合法劳动权益，特依据《中华人民共和国劳动争议调解仲裁法》之规定向贵委申请仲裁，恳请依法裁决支持申请人的全部仲裁请求。”

## 二、 当事人口语 vs 规范司法法言法语对照表（实战转换库）

| 场景类别 | ❌ 当事人常见情绪化/口语表述 | ✅ 标准劳动仲裁法言法语表述 |
| :--- | :--- | :--- |
| **1. 入职与建立关系** | “我是2021年5月10号去他们公司上班的，做程序员，说好一个月一万八。” | “申请人于 2021年5月10日入职被申请人处，担任后端研发工程师一职，双方约定月标准工资为人民币 18,000.00 元（税前应发），自入职之日起双方依法建立劳动关系（详见证据1、证据2）。” |
| **2. 未签书面合同** | “老板一直拖着不给我签合同，问了好几次都推脱。” | “申请人自 2023年3月1日入职起，虽多次催促，但被申请人始终未依法与申请人订立书面劳动合同，违反了《中华人民共和国劳动合同法》第十条、第八十二条之强制性规定。” |
| **3. 口头辞退 / 踢出群聊** | “主管把我叫到会议室说不用来了，下午就把我企业微信和打卡权限封了，太欺负人了！” | “2024年8月15日，被申请人单方口头通知与申请人解除劳动关系，并于当日单方关停申请人的企业微信办公账号、办公系统权限及考勤门禁权限，致使申请人客观上无法继续提供劳动（详见证据6、证据7）。” |
| **4. 借故“绩效不胜任”辞退** | “HR硬说我绩效打C不合格要把我开了，根本没给我培训过，考核也是领导瞎打分的。” | “被申请人虽以申请人‘不能胜任工作’为由单方解除劳动合同，但被申请人既未向申请人公示过合法有效的绩效考核标准，亦未在考核后依法对申请人进行专项培训或调整工作岗位，更未履行再次考核程序，明显违反《中华人民共和国劳动合同法》第四十条第（二）项之法定程序要件，构成违法解除。” |
| **5. 借故“部门裁撤/架构调整”辞退** | “公司说我们部门解散了，让我直接走人，一分钱不赔。” | “被申请人以‘内部组织架构调整’为由单方辞退申请人，不属于《劳动合同法》第四十条第（三）项规定的‘订立时所依据的客观情况发生重大变化’，且被申请人未就变更劳动合同与申请人进行任何诚意协商，亦未事先将解除理由通知工会（违反《劳动合同法》第四十三条），系典型的违法解除劳动合同行为。” |
| **6. 强迫调岗降薪 / 穿小鞋** | “公司故意把我从研发调去外地做销售，工资还砍了一半，逼我自己辞职。” | “被申请人在未与申请人协商一致的情况下，单方强制将申请人工作岗位由研发岗变更至不具备相关性之销售岗，并将工作地点变更至异地、大幅降低劳动报酬，该调岗行为不具备企业用工自主权之合法性与合理性，具有明显的惩罚性与逼迫离职恶意。” |
| **7. 被迫解除劳动合同** | “公司欠了我两个月工资还不交社保，我实在干不下去了就发了离职通知。” | “因被申请人无故拖欠申请人 2024年6月至7月劳动报酬且未依法缴纳社会保险费，申请人已于 2024年8月10日依据《中华人民共和国劳动合同法》第三十八条第一款第（二）、（三）项之规定，向被申请人正式送达《被迫解除劳动合同通知书》（详见证据5），被申请人应依法向申请人支付经济补偿金。” |
| **8. 索要加班费与倒置举证** | “我周末经常在公司加班，打卡记录在公司后台，我手机里只有工作群发代码的截图。” | “在职期间，被申请人多次安排申请人于休息日加班共计 20 小时，有企业微信工作群沟通记录及加班审批截图为证（详见证据5）。鉴于完整原始考勤记录由被申请人掌握管理，申请人依法申请贵委责令被申请人限期提交考勤原始台账；若其拒不提供，应依据《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第四十二条、第四十四条承担不利法律后果。” |
