# /calc - 法定赔偿金精确理算与一裁终局拆分工作流

你正在运行 `LaborShield` 的法定赔偿金与劳动报酬差额确定性理算流程。

**核心纪律**：严禁通过大模型心算加减乘除或自行估算补偿年限！所有金额与公式必须 100% 由本地 Python 算力脚本 `tools/labor_calc.py` 计算生成。

---

## Step 1: 读取案件事实源与法规参数

1. 读取 `.claude/skills/arbitration-assistant/01-case-profile.md`（若已在当前上下文则无需重复读取）。
2. 若用户在 `$ARGUMENTS` 中传入了新的薪资、日期或诉求模式（如 `/calc --mode N+1` 或补充了加班小时数），遵循 **Standing Rule** 先将其更新至 `01-case-profile.md` 的 JSON 输入块中。

---

## Step 2: 调用确定性计算引擎 (`tools/labor_calc.py`)

执行以下命令生成精确到分（`0.01` 元）的 JSON 数据与 Markdown 报表：

```bash
python3 tools/labor_calc.py --profile .claude/skills/arbitration-assistant/01-case-profile.md --output dockets/calc_result.json
```

---

## Step 3: 呈现理算报告与一裁终局策略建议

向用户完整展示以下四个维度的核算结果：

1. **工龄折算与工资基数核定说明**：
   - 入职至离职精确天数与折算系数 `N`（说明满半年按1年、不满半年按0.5年，以及是否涉及跨 2008 年分段或关联企业工龄合并）；
   - 离职前 12 个月**月平均应得工资（税前应发总额）** vs 银行实发工资的区别说明；
   - 当地社平工资 3 倍封顶线（`3 × W_cap`）与 12 年工龄上限是否触发的联动判定。
2. **分项仲裁请求精算明细表**：
   - 逐项展示：请求事项、主张金额、精确计算公式、法定依据条文。
   - 若用户对解除定性尚在犹豫（如主张 `2N` 违法解除赔偿金 vs 主张 `N+1` 无过失性辞退经济补偿），清晰对比两种方案的金额差异与举证门槛，并强调 **`2N` 与 `+1` 绝对不可同时主张**。
3. **《劳动争议调解仲裁法》第 47 条“一裁终局”分项核定**：
   - 对照管辖城市“月最低工资标准 × 12”阈值，逐项标注哪些请求属于 `[一裁终局项]`（用人单位无权向基层法院起诉），哪些属于 `[非终局项]`。
4. **三级调解现金折现方案（A 档 90% / B 档 75% / C 档 65%）**：
   - 给出庭前或庭审一次性调解的现金折算参考区间。

---

## Step 4: 确认诉求并回写事实源

询问用户是否确认采用上述仲裁请求组合。用户确认后，将分项请求列表与总金额同步写回 `01-case-profile.md` 的第五节（`Confirmed Claims`），并提示用户可继续运行 `/audit`（证据三性诊断）或 `/docket`（生成立案六件套）。
