# 原始证据只读归档区 (`evidence/`)

> **安全与只读原则**：本目录用于存放申请人的原始证据文件（PDF、图片、导出表格、录音及文字稿）。AI 工具对本目录仅执行**只读扫描与页码编排**，绝不修改任何原始证据文件。用人单位出具的文件在本目录中受 **Trust Boundary (`07-employer-research.md`)** 隔离保护。

---

## 一、 六大标准证据分类子目录

请将您的案件证据材料按以下 6 个分类放入对应子目录，并建议采用 `YYYY-MM-DD_证据简述.后缀` 命名（方便 `tools/evidence_timeline.py` 自动提取时间戳）：

| 子目录名称 | 应放入的材料清单 | 取证合规关键提示 |
| :--- | :--- | :--- |
| `01_identity_registration/` | 1. 申请人身份证正反面复印件/扫描件<br>2. 被申请人“国家企业信用信息公示系统（`gsxt.gov.cn`）”完整企业信用信息打印件 | 若涉及劳务派遣或关联公司混同用工，需同时放入两家公司的工商公示信息。 |
| `02_contracts_rules/` | 1. 历次签订的《劳动合同》及补充协议<br>2. 入职《录用通知书 (Offer)》、入职登记表、工牌照片、转正通知 | 若单位未签书面劳动合同，放入入职沟通微信、工牌、OA账号截图以证明实际用工起始日。 |
| `03_salary_social_security/` | 1. 银行官方导出的近 12~24 个月《工资交易流水明细》（加盖银行电子章）<br>2. **国家税务总局“个人所得税 App”**导出的《收入纳税明细》截图（还原税前应得工资的核心铁证！）<br>3. 工资条/电子薪资单、年终奖发放记录<br>4. 人社局/支付宝/粤省事导出的《社会保险参保缴费明细表》与公积金缴存明细 | **务必提供个税 App 收入明细**：银行流水仅显示扣完社保公积金和个税后的“实发工资”，而法定 `N/2N` 基数为“税前应得工资”，个税 App 申报收入可直接锁定税前基数。 |
| `04_attendance_overtime/` | 1. 企业微信/钉钉/飞书考勤打卡记录截图<br>2. 加班审批单、周末/深夜工作群交付工作成果记录、邮件发送记录<br>3. OA 系统年休假剩余天数截图 | 若后台完整考勤表被公司封禁，保留现有截图即可，`/docket` 会自动生成《责令用人单位提交考勤原始记录申请》。 |
| `05_termination_notices/` | 1. 公司出具的《解除/终止劳动合同通知书》《辞退通知》<br>2. 公司发出的《调岗降薪通知》《绩效改进计划 (PIP)》<br>3. 若系被迫解除：本人发出的《被迫解除劳动合同通知书》及 **EMS 邮政特快专递详情单 + 物流签收截图**<br>4. 《工作交接单》《离职证明》 | **切勿签署写有“因个人原因辞职”或“双方无任何劳动争议”的空白格式表格！** |
| `06_communications_recordings/` | 1. 微信/钉钉/飞书完整聊天记录截图<br>2. 现场辞退谈话录音原始音频（`.mp3`/`.m4a`/`.wav`）及配套的《录音文字整理稿》 | • **微信/钉钉必须满足“三连闭环”**：① 对方个人信息主页（含微信号/手机号/实名架构）截图 + ② 连续无删减对话截图 + ③ 原始手机备查。<br>• **录音必须配套文字整理稿**，并在关键争议处标注 `[MM:SS]` 秒级时间戳。 |
