# 劳动人事争议仲裁交付物目录 (`dockets/`)

本目录存放由 `/docket` 工作流与 `tools/generate_docket_docx.py` 确定性渲染、并通过 `tools/verify_docket.py` 静态校验通过的最终立案文书包。

---

## 一、 每个案件子目录包含的标准交付物 (`01`~`07`)

| 文件名 | 是否递交仲裁院 | 现场窗口递交份数（以 1 家被申请人为例） | 用途说明 |
| :--- | :---: | :---: | :--- |
| `01_劳动人事争议仲裁申请书_标准式.docx` | ✅ **必交** | **正本 1 份 + 副本 1 份**（若有 2 家被申请人则准备正本 1 份 + 副本 2 份） | 传统叙述式标准申请书，申请人本人须在落款处亲笔签名并捺手印。 |
| `02_劳动人事争议仲裁要素表_要素式.docx` | ✅ **必交** | **正本 1 份 + 副本 1 份** | 18 项审理核心要素表（适配深圳、广东、北京、上海、浙江等地要素式办案规范，亦可直接复制填入线上仲裁小程序）。 |

| `06_程序性附件_法定代表人证明及授权委托书模板.docx` | ⭕ 按需提交 | **1 份** | 含被申请人工商负责人身份证明书（部分仲裁院要求提交）及委托近亲属/律师代理时的《授权委托书》。 |
| `07_庭审举证质证与调解应对手册.md` | ❌ **绝不递交** | 自留 1 份带入庭审现场 | **申请人内部作战卡**！包含仲裁员必问问答、HR 8大抗辩三性反驳词、举证倒置申请口述词及 A/B/C 三级调解底线。 |

## 二、 现场窗口与线上小程序立案实操清单

1. **装订与页码规范**：
   - 将所有证据复印件按 `04_申请人证据目录及证明目的清单.docx` 中的页码范围（`P1`, `P2`, ...）在右上角或右下角用黑色签字笔清晰手写编上连续页码；
   - **切勿将证据原件交由仲裁院装入卷宗**（录音文件按当地仲裁院要求刻录光盘或拷入专用 U 盘，并附上纸质《录音文字整理稿》）。
2. **线上预审平台入口参考**：
   - **全国通用**：人力资源和社会保障部政务服务平台（或微信搜索对应省/市人社小程序）；
   - **广东/深圳**：“粤省事”小程序 → 劳动仲裁 / “深圳市人力资源和社会保障局”官网劳动人事争议仲裁服务大厅；
   - **上海**：“随申办”App/小程序 → 劳动人事争议调解仲裁；
   - **北京**：“京通”小程序 / 北京市人力资源和社会保障局官网 → 劳动人事争议调解仲裁网上服务；
   - **浙江/杭州**：“浙里办”App → 浙里调解 / 劳动仲裁。
